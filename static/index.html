Setup & connection

Kitten Studio uses its own kitten-studio\.venv. It never runs inside your older KittenTTS environment.

Models download automatically from Hugging Face if missing. To authenticate, set the standard HF_TOKEN environment variable or create a local .env file containing HF_TOKEN=your_new_token, then restart. The app never displays your token, and a token is not required for public models.

Windows launcher RUN_WINDOWS.bat defaults to online with cache reuse. Use RUN_WINDOWS_OFFLINE.bat only after all model assets are cached.

Downloads still depend on Hugging Face connectivity. If Windows reports WinError 10054, try a different network or retry; authentication cannot fix a blocked TLS connection.
